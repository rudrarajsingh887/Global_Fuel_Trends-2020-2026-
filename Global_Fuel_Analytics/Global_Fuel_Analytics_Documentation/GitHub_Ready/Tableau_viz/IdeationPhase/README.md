# Ideation Phase — Global Fuel Prices and Taxation Trends

**Project owner:** Rudraraj Singh Bhati  
**Project title:** Global Fuel Prices and Taxation Trends: A Comprehensive Global Performance Intelligence Report

## Problem to solve
Global fuel prices and taxation indicators vary across countries, regions and time. Raw rows make comparisons laborious and can hide important patterns. The project uses interactive Tableau views to make the information easier to compare and interpret.

## Problem statements
1. **Policy analyst / researcher:** I need to compare fuel prices and tax levels by country and year, but the data spans many rows and categories, making manual review slow and increasing the chance of overlooking patterns.
2. **Student / journalist / informed reader:** I want to understand how petrol, diesel, LPG and crude-oil indicators vary, but the patterns are difficult to see from a raw table alone.

## Intended viewer — empathy map
- **Says:** “Which regions have higher fuel prices or tax percentages?” “How did prices change over time?”
- **Thinks:** The raw data may contain useful patterns, but comparisons should be consistent and transparent.
- **Does:** Opens the dashboard, changes relevant filters and compares maps, trend lines, KPIs and tax charts.
- **Feels:** Needs clarity, readable labels and confidence in data quality.
- **Pains:** Large tables, unclear units, inconsistent categories and charts that are difficult to compare.
- **Gains:** An overview, interactive exploration, a guided Story and shareable links.

*The persona is a design assumption; no formal interview study was supplied.*

## Selected objective
Build a descriptive, interactive Tableau dashboard and seven-scene Story from the CSV dataset, publish both to Tableau Public, and present them through a project-focused web interface.
