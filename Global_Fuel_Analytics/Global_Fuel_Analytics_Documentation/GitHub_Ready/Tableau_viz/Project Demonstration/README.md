# Project Demonstration

## Required deliverable
Record a 5–7 minute screen-share video explaining the project end-to-end. The detailed spoken script is in `08_Project_Demonstration/End_to_End_Recording_Script.docx` in the documentation pack.

## Suggested 6:30 flow
| Time | Section | What to show |
|---|---|---|
| 0:00–0:45 | Introduction/problem | Name, project title and question. |
| 0:45–2:00 | Data/preparation | CSV fields, coverage and quality checks. |
| 2:00–3:35 | Dashboard | KPIs, maps, line charts, tax/country comparisons; demonstrate filters. |
| 3:35–4:45 | Story | Navigate all seven scenes. |
| 4:45–5:35 | Insights | Discuss findings carefully, without causal claims. |
| 5:35–6:30 | Web integration/conclusion | Show final website embeds and summarize work. |

## Before recording
- Pre-open the website, dashboard and Story.
- Confirm that the world-map hero, dashboard charts and all seven Story scenes display.
- Test a Date or Region filter.
- Keep browser zoom large enough to read.
- Record microphone audio and check the final duration.
- Save the video and screenshots; don't claim an embed passed if it isn't visible in the final browser.

## Solo project note
The project owner is the sole presenter. Team-involvement and communication templates should be marked as solo-project rather than inventing additional team members.
